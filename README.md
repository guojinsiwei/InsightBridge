# 知桥 InsightBridge

知桥是一款轻量的跨语种观点比对 Web 工具，面向新闻阅读、资料调研和课堂讨论场景。用户粘贴两段中文或英文文本后，可以得到主题重合度、立场倾向、共同关注、差异焦点和代表性表达。

## 项目亮点

- 双语关键词归一化：把常见中英文概念映射到统一语义标签。
- 可解释结果：每项结论保留原文代表句，便于用户核对。
- 隐私友好：分析完全在浏览器本地完成，无需登录或上传文本。
- 零配置运行：项目由原生 HTML、CSS 和 JavaScript 构成，可直接部署到任意静态托管平台。
- 响应式界面：支持桌面和手机浏览，并提供内置示例用于现场演示。

## 快速开始

直接用浏览器打开 `dist/index.html` 即可使用。若希望通过本地 HTTP 服务访问，可以在项目目录运行：

```bash
python -m http.server 8000 -d dist
```

然后访问 `http://localhost:8000`。

## 自检

项目无需安装依赖。使用 Node.js 运行静态结构检查：

```bash
node tests/smoke.mjs
```

## 技术说明

当前版本采用可解释的本地启发式分析：提取关键词、进行中英文概念归一化、计算集合重合度，并依据积极/审慎词汇生成倾向标签。它适合作为实践周的可运行原型。后续可以接入大语言模型 API，扩展语义聚类、引用溯源和多文档对比能力。
