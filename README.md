# 知桥 InsightBridge

知桥是一款轻量的跨语种观点比对 Web 工具，面向新闻阅读、资料调研和课堂讨论。用户粘贴两段中文或英文文本后，可以得到已识别概念的主题重合度、词汇倾向、共同关注、差异焦点和代表性表达。

## 项目亮点

- 跨语种观点比对：把常见中英文概念映射到统一标签，再对照两段文本。
- 可解释分析：重合度使用 Jaccard 集合计算，倾向来自预置词表命中，结果可回溯到原文句子。
- 隐私友好：分析完全在浏览器本地完成，无需登录或上传文本。
- 零配置运行：原生 HTML、CSS 和 JavaScript，可直接打开或部署到任意静态托管。
- 现场可演示：内置智慧城市、科研摘要、湾区出海三组示例。

## 快速开始

用浏览器直接打开 `dist/index.html`。若希望通过本地 HTTP 服务访问：

```bash
python -m http.server 8000 -d dist
```

然后访问 `http://localhost:8000`。

## 自检

项目无需安装依赖。使用 Node.js 18 或更高版本运行静态结构检查和行为回归测试：

```bash
node tests/smoke.mjs
node --test tests/analysis.test.mjs tests/interaction.test.mjs
```

回归测试覆盖词表覆盖不足、中英概念归一化、词边界与常见否定、原文证据、分句，以及修改输入、切换语言/示例、交换、清空和快捷键提交。交互测试使用轻量 DOM 适配器执行实际页面脚本，不包含真实浏览器布局或屏幕阅读器验证。

## 技术说明

当前版本是可解释的本地启发式分析，不是大语言模型语义理解系统。流程为：关键词提取 → 中英概念归一化 → 集合重合度 → 积极/审慎词表倾向。适合作为实践周可运行原型。后续可接入大模型 API，扩展语义聚类、引用溯源和多文档对比。

- 任一文本未匹配到概念时，显示“词表覆盖不足”，不计算重合度或断言差异。两边均有匹配时，百分比只描述已识别概念的集合重合，不代表立场一致或全文语义相似。
- 中英词条采用同一套匹配规则；英文按词边界匹配，同一位置优先采用更长的概念短语。匹配结果保留原文位置，代表句使用相同的概念规则。
- 词汇倾向按不同词条计数，展示命中词并排除部分常见否定表达。零命中显示“未识别”，两类词接近时显示“混合”。复杂否定、反讽、词义歧义和跨句关系仍需人工核对。
- 修改文本、语言、示例或交换输入后，旧结果立即隐藏，需重新分析。分析同步完成，不设置人为等待时间。

## 目录结构

```text
dist/
  index.html   页面结构
  styles.css   视觉与响应式样式
  analysis.js  概念匹配、词汇倾向、分句与比较的纯函数
  app.js       示例、结果展示和交互状态
tests/
  smoke.mjs    零依赖静态自检
  analysis.test.mjs     分析行为回归测试
  interaction.test.mjs  交互状态回归测试
  helpers.mjs           脚本加载和轻量 DOM 测试适配器
.openai/
  hosting.json 托管配置
```
